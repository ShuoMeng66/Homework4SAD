# 口腔诊所管理系统

严格依据《口腔诊所管理系统系统分析与设计报告》实现的口腔诊所业务系统，覆盖报告全部 8 章设计内容：25 张业务关系表、61 个外键、欠款查询视图（`v_bill_debt`）、UC-01 ~ UC-06 业务规约、全部表 23 约束与表 25 七项统计口径。

## 访问地址

- **GitHub Page**：https://shuomeng66.github.io/Homework4SAD/

## 架构特点

- **轻量低内存后端**：基于 Python 3.12 标准库（`http.server` + `sqlite3`），无重型 Web 框架常驻开销，内存占用约 16–20 MB（`MemoryMax=128M`）。
- **真正的关系型数据库**：后端直接依据 [server/schema.sql](server/schema.sql) 落地 25 张业务关系表、61 个外键、`v_bill_debt` 欠款查询视图以及表 23 全部唯一/检查约束与索引，附件文件独立托管于文件存储目录。
- **严格服务端鉴权与数据隔离**：采用 HMAC 会话令牌，所有读写接口按角色隔离数据与操作权限；患者端仅接收本人数据与修复件三态投影（制作中/待试戴/可取件），统计视图按角色脱敏。
