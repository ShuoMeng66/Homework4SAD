> 报告未给出的必要页面/账号信息按用户授权补充，并注明理由。

### 扩展路径（必须实现）
- UC-01：2a 无法确认同一患者→建待核对档案不合并；5a 医生/诊室冲突→返回冲突原因和候选时段；6a 改约→保留变更历史；7a 保存失败→保留重试信息。
- UC-02：2a 未找到项目→选已有项目或交主管；3a 重复收费→拒绝；6a 支付失败→保留原因欠款不清零；6b 待确认→保留状态用原请求号核对。
- UC-03：4a 基础信息缺失→转维护；4b 缺牙位/必要附件→保持草稿；6a 发送失败→保留待重试；7a 技工所拒收→标记待处理；8a 试戴不合格→创建返工保留历史。
- UC-04：2a 数据量不足→显示样本量不作趋势判断；2b 无法关联→标记数据质量异常；5a 其他渠道完成→负责人确认保留原因。

## 3. 业务规则（出处：BR-01~BR-08，第4、6、8章）

| 规则 | 内容 |
| --- | --- |
| BR-01 | 同一医生或诊室同一时段不能有两个有效预约 |
| BR-02 | 预约状态为待确认/已确认/已到诊/已完成/已取消/爽约；取消与爽约不占用未来时段 |
| BR-03 | 应收=项目金额-合法折扣；欠款=应收-已收 |
| BR-04 | 支付状态为成功/失败/待确认/退款；失败与待确认不计入已收 |
| BR-05 | 订单状态为草稿/已发送/已接收/试戴/质量确认/已交货/返工/取消 |
| BR-06 | 已交货订单只能通过返工或更正记录修改，不得直接回退 |
| BR-07 | 待确认支付和未关闭订单不计入完成量 |
| BR-08 | 指标可追溯到原始记录；逾期按承诺日期与当前日期判断 |

## 4. 订单状态机（出处：表17）

| 转换 | 触发 | 条件 |
| --- | --- | --- |
| 草稿→已发送 | 医生确认发送 | 已选产品、数量、≥1 有效牙位，必要附件齐全 |
| 草稿/已发送→已取消 | 医生或前台取消 | 未进入加工，保留原因 |
| 已发送→已接收 | 技工所回执 | 订单存在，来源与事件号未重复 |
| 已接收→试戴 | 技工所提交试戴结果 | 回执已确认，订单仍有效 |
| 试戴→质量确认/返工 | 医生确认试戴结果 | 不合格保留原结果并追加返工进展 |
| 返工→试戴 | 技工所再次提交 | 保留返工历史，形成新试戴进展 |
| 质量确认→已交货 | 前台或医生确认交货 | 有时间和经办人，不得直接回退 |

## 5. 统计口径（出处：表24）

| 指标 | 口径 |
| --- | --- |
| 预约确认周期中位数 | 期间内已确认预约的创建→确认时长中位数；取消/待确认/爽约不纳入 |
| 预约兑现率 | 分母=期间开始的已确认/已到诊/已完成/爽约预约；分子=已到诊或已完成 |
| 欠款回收率 | 固定期初欠款队列，分母=期初未收余额，分子=期间回收额扣成功退款 |
| 订单按期交付率 | 分母=承诺交期在已结束期间的已发送未取消订单；分子=交货不晚于承诺日 |
| 记录关联完整度 | 分母=期间收费与订单记录；分子=能关联有效患者/诊疗/必要明细的记录 |

比率分母为零显示"无可计算样本"。
