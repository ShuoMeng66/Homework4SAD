## 3. 核心数据模型与约束（出处：第 8 章表 21 ~ 表 23、8.8）

- **25 张业务表、61 个外键 + `v_bill_debt` 欠款查询视图**：`clinic`、`clinic_room`、`basic_option`、`employee`、`employee_role`、`appointment_type`、`patient`、`schedule`、`appointment`、`appointment_event`、`encounter`、`recall`、`treatment_plan`、`plan_item`、`price_item`、`product`、`dental_lab`、`bill`、`bill_line`、`payment`、`dental_order`、`order_tooth`、`order_event`、`order_attachment`、`reminder`。
- **表 23 唯一性与检查约束**：排班时长被切片整除、号源不单建表动态推导；`encounter.appointment_id` 唯一且患者/医生一致；`recall.encounter_id` 唯一且关闭后禁回退；`bill_line` 与 `payment` 分别聚合后再关联计算欠款视图；支付 `request_no` 与非空 `external_txn_no` 唯一、累计退款不超原收款；义齿进展 `(order_id, source, event_no)` 联合唯一；提醒强制关联单一目标且患者修复通知脱敏内部单号、技工所与返工细节。

## 4. 统计口径（出处：表 25）

1. **预约确认周期中位数**：期间内已确认预约从 `created_at` 到 `confirmed_at` 时长中位数（取消/待确认/爽约不纳入）。
2. **预约兑现率**：分母为期间开始的已确认/已到诊/已完成/爽约预约，分子为已到诊或已完成。
3. **椅位利用率**：分子为期间内各诊室已到诊/已完成预约实际占用时长（同诊室重叠合并，不重复计），分母为各诊室有效排班开放总时长（停诊段扣除）。
4. **医生工作量**：按具备医生岗位员工聚合期间接诊人次、完成治疗计划项数与已交货义齿单数。
5. **欠款回收率**：锁定统计期初未结清收费单队列，分母为期初欠款总额，分子为该批单据期间成功收款减成功退款；期内新形成欠款单列展示。
6. **订单按期交付率**：分母为承诺交期落在已结束期间且非草稿/非取消的义齿订单，分子为实际交货日期不晚于承诺交期的已交货订单。
7. **记录关联完整度**：分母为期间内收费单与义齿订单总数，分子为关联链（有效患者、诊疗、必要牙位/明细及计划双向引用）完整的单据数，同时单列疑似重复患者档案数。
