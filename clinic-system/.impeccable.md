# Design Context — 口腔诊所管理系统

## Target audience
前台接待、口腔医生、收费员、诊所负责人、系统管理员及自助端患者（见报告第 3 章表 5 与系统用例图）。
工作场景：前台高并发建档与按号源排程、医生椅旁录入病历与分期治疗计划及义齿委托、收费员分次收款与核对退款、负责人查看七项经营统计与提醒、患者未来两周自助预约与查看修复三态进度。

## Use cases
- UC-01 登记患者并按号源预约（含待核对档案、防冲突、加号留痕、改约历史与召回联动）
- UC-02 录入收费、分次收款与欠款跟进（含折扣校验、重复收费拦截、待确认核对与退款重算）
- UC-03 录入义齿订单并追踪交付（含多牙位、独立附件托管、幂等回执、试戴返工与交货后更正）
- UC-04 查询统计与订单提醒（含表 25 七项口径、小样本提示、明细下钻导出与线下结单）
- UC-05 患者自助预约与进度查询（含 14 天标准项目限制、爽约熔断与修复三态脱敏投影）
- UC-06 制定并执行分期治疗计划（含 FDI 牙位点选、锁价快照及执行自动衔接收费单与技工单）

## Brand personality / tone
**瑞士临床工作站风（Swiss Clinical Workstation）**：冷静、克制、专业可信。
采用哑光深海蓝导航脊背（`#0C1726`）、临床钴蓝交互强调色（`#1B56B5`）与雾石色纸感工作区（`#F3F5F8`）；金额与编号统一使用等宽表格数字（`tabular-nums`），状态采用高辨识度细线胶囊标签。

## Constraints
- 原生 HTML / CSS / JS，零构建静态托管于 GitHub Pages；后端基于 Python 标准库 + SQLite 关系库（25 张业务表、61 个外键、`v_bill_debt` 视图）。
- 强制服务端权威校验与角色最小权限隔离（RBAC），关键业务状态与主数据变更全量写入审计日志。
- 可访问性：正文对比度 ≥ 4.5:1，键盘焦点清晰可见，尊重 `prefers-reduced-motion`。
