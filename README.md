## 作业概述

本作业围绕口腔诊所的患者登记、预约诊疗、费用结算和义齿委托业务，完成业务建模、需求分析、分析模型及数据库逻辑设计。报告从现状流程中的资料分散、预约冲突和订单进度核对问题出发，明确系统范围、岗位职责、业务规则与数据关联。

[查看完整报告：陈荣杰_8305240320_系统分析与设计报告.pdf](陈荣杰_8305240320_系统分析与设计报告.pdf)

## 报告内容

1. **愿景与业务建模**：界定项目目标和业务参与者，对比现状与改进后的业务流程。
2. **系统需求与用例规约**：说明功能范围、主要交互、基本路径、异常处理及验收要求。
3. **分析类与分析序列模型**：划分边界类、控制类和实体类，描述预约、收费、义齿订单及统计提醒中的对象协作。
4. **数据库逻辑设计**：设计 20 张关系表、207 个字段和 44 个外键，说明主外键、唯一性约束、事务边界与统计口径。

报告共含 18 张模型图，包括业务与系统用例图、业务序列图、核心数据域关系图、用例规约关系图、分析类图、分析序列图，以及完整和局部数据库设计图。
