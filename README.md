# 口腔诊所管理系统

中南大学商学院《系统分析与设计》课程项目，完整流程涵盖 **需求分析 → 系统设计 → 编码开发 → 测试交付**。

## 项目简介

本项目面向中小型口腔诊所的日常经营场景，目标是建立一套覆盖 **患者登记与预约、诊疗记录、收费与欠费处理、义齿订单追踪、经营查询统计** 的信息化管理系统，替代目前依赖纸质台账与人工记忆的作业方式。

> **当前进度**：本仓库本次提交的是**系统分析与设计阶段的设计报告**，编码开发部分尚未开始，后续实现会继续补充到本仓库。
