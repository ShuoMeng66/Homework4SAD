# 口腔诊所管理系统

中南大学商学院《系统分析与设计》课程项目，完整流程涵盖 **需求分析 → 系统设计 → 编码开发 → 测试交付**。

## 项目简介

本项目面向中小型口腔诊所的日常经营场景，目标是建立一套覆盖 **患者登记与预约、诊疗记录、收费与欠费处理、义齿订单追踪、经营查询统计** 的信息化管理系统，替代目前依赖纸质台账与人工记忆的作业方式。

> **当前进度**：本仓库本次提交的是**系统分析与设计阶段的设计报告**，编码开发部分尚未开始，后续实现会继续补充到本仓库。

## 分析与数据库设计

按课程材料第 280 页起的方法，分析类图使用类名、属性、操作分栏，标注可见性、类型、多重性和组合关系；分析序列图使用边界、控制和实体对象、生命线、执行条、调用与返回。

分析序列图中的人员统一复用图 2、图 3 的圆框人形及右下斜线，技工所沿用原有机构符号；字体采用相同的微软雅黑。共用符号保存在 `figures/sequence_symbols.tex`，报告和独立图 PDF 使用同一份定义。

- 3 张分析类图：患者与预约、收费与支付、义齿订单与进展。
- 5 张分析序列图：登记预约、收费、订单发送、技工所回执、统计与待处理订单。
- 4 张数据库设计图：患者预约、费用、义齿订单、基础信息与附件提醒。

数据库共 21 张逻辑表、39 个外键，覆盖基础信息维护、患者查询、诊疗、预约、收费欠款、订单、附件、统计与提醒。表结构组织参考 Shopify ERD 和 Quickbooks 1.0 ERD；按诊所需求拆分明细、支付及变更历史。报告同时列出唯一性、业务约束、事务边界和统计口径，尚未进入数据库及应用程序实现。

## 重新编译

使用 XeLaTeX。当前模板采用 Windows 中文字体，需安装 TeX Live 或其他包含 `ctex`、TikZ 的 TeX 发行版。在仓库根目录运行两次，以更新目录、图表编号和交叉引用：

```powershell
xelatex -interaction=nonstopmode -halt-on-error report.tex
xelatex -interaction=nonstopmode -halt-on-error report.tex
```

新增图的 `.tex` 已纳入仓库，可直接编译。调整模型后，可先用 Python 3 运行 `python build_analysis_figures.py` 重新生成；该脚本只使用标准库，并检查主键、重复字段与外键目标。生成的 `report.pdf` 是编译产物，仓库中的正式报告使用上表所列文件名。

所有图统一存放在 `figures/`。运行 `python build_figure_pdfs.py` 可更新图 5 和图 7--18 的独立 PDF；临时编译文件写入忽略目录 `tmp/`。报告中的这些图仍直接引用 TikZ 源码，由 LaTeX 排版。
